# ERT Modpacks

Personal tool to organize my Minecraft modpacks.

ERT Modpacks is a local web page (runs on my Windows PC with a small local server) that keeps a library of mods and the modpacks that use them.

## What it does
- Keeps one library of mods and several modpacks that reference them.
- Reads mod metadata from CurseForge and Modrinth (name, logo, author, versions, dependencies and declared incompatibilities) so my lists stay up to date.
- Checks compatibility: Minecraft version, mod loader, missing dependencies and incompatibilities declared by authors.
- Reads Minecraft crash reports to explain errors and keeps my own list of known conflicts.
- Exports a public mod list with links to each mod's official page, and a standard CurseForge modpack manifest for the CurseForge app.

## What it does not do
- It does not distribute, re-host or bundle mod files.
- It is not sold and has no subscription. Personal, non-commercial use.
